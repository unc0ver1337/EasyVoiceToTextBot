# Easy Voice To Text

![Easy Voice To Text](branding/description.jpg)

Telegram-бот на Python: **голосовые, кружочки, аудио и видео → текст** через **whisper.cpp + Vulkan + Whisper Large V3 Turbo Q5_0**. Создан и проверен на Windows с Radeon RX 580.

Это исходный код версии из `Documents/EasyVoiceToTextBot`. `bot.py`, `engine.py`, скрипты запуска и существующие проверки перенесены без изменения поведения. Для распространения добавлены установщик, пример конфигурации и эта инструкция. Личный токен, записи, логи, ключи, виртуальное окружение и бинарные модели не опубликованы.

## Как пользоваться

1. Отправьте боту голосовое, кружочек, аудио, видео или аудио/видео как документ.
2. Нажмите **Қазақша / Русский / English / Авто** под записью.
3. После выбора языка начинается обработка. Короткий текст заменит сообщение статуса; длинная расшифровка придёт TXT-файлом с предпросмотром.

Вводить slash-команды не нужно. Есть кнопки **Помощь**, **Состояние**, **Конфиденциальность**, а под запросом — **Отменить**. Язык выбирается для каждой записи. Telegram при первом запуске может показывать стандартную кнопку Start.

## Требования

- Windows 10/11 **x64**, Python **3.10+ x64** (исходная версия проверялась с Python 3.14).
- Драйвер видеокарты с Vulkan. Подтверждена работа на Radeon RX 580; другие GPU нужно проверять отдельно.
- Интернет для Telegram и первоначального скачивания зависимостей.
- Примерно 1 ГБ свободного места, плюс место для временного аудио. Потребление RAM/VRAM зависит от записи и окружения.
- Собственный токен от [@BotFather](https://t.me/BotFather).

## Установка с нуля

1. Нажмите **Code → Download ZIP** в GitHub и распакуйте архив, либо клонируйте репозиторий.
2. Установите [Python для Windows](https://www.python.org/downloads/windows/), включая Python Launcher или пункт Add Python to PATH.
3. Запустите **setup.bat**. Он создаст `.venv`, установит Python-зависимости и FFmpeg, скачает Windows Vulkan runtime и модель Turbo (~574 МБ), проверит SHA-256 и создаст `config.json` из примера. Дождитесь окончания.
4. Откройте **config.json** и замените `PUT_YOUR_BOTFATHER_TOKEN_HERE` на **свой** токен. Остальные значения можно оставить как есть. Никому не отправляйте этот файл.
5. Дважды нажмите **start.bat**, затем откройте своего бота в Telegram.

Установщик **не запускает бота** и **не включает автозапуск Windows**. Повторная установка сохраняет существующий `config.json`. Запуск установщика требует доступа к GitHub, Hugging Face и PyPI. Если checksum не совпадает, файл не устанавливается: не отключайте проверку без выяснения причины.

Эквивалент установки из терминала:

```powershell
py -3 install.py
# Затем впишите токен в config.json
.\start.bat
```

## Запуск и остановка

- **start.bat** запускает бота и повторяет запуск через 10 секунд после аварийного выхода Python.
- **stop.bat** запрашивает штатную остановку. Обычно она занимает до 5 секунд; при сетевых задержках может дольше.
- Повторный запуск защищён файловой блокировкой: второй экземпляр не начинает получать сообщения.
- Только один процесс с одним токеном должен использовать Telegram long polling. Остановите копию бота на другом ПК, прежде чем запускать этот экземпляр.
- В комплекте нет Windows-службы и автоматической загрузки при входе в систему. Для постоянной доступности ПК должен оставаться включённым и подключённым к интернету; во сне и при выключении бот недоступен.

## Как освобождается видеопамять

Python получает сообщения постоянно, а `whisper-server.exe` запускается по требованию после выбора языка. Через **600 секунд после последнего распознавания**, когда нет активной обработки и очереди, сервер завершается. Проверка выполняется каждые 5 секунд. Следующий запрос загружает модель снова.

При отмене активного распознавания процесс Whisper тоже завершается. Windows Job Object связывает его время жизни с Python, чтобы модель не оставалась в памяти при аварии бота. Сервер доступен только на `127.0.0.1:18088`.

Режим фиксирован: Turbo Q5_0, beam search 5. Точность не гарантируется: особенно внимательно проверяйте казахские имена, даты, числа и шумную речь. Это транскрипция, а не исправление или пересказ.

## Ограничения и антиспам

| Ограничение по умолчанию | Значение |
|---|---:|
| Размер входного файла | 20 МБ — лимит скачивания облачного Telegram Bot API |
| Длительность записи | 30 минут |
| Запросов на одного пользователя одновременно | 1 |
| Пауза между принятыми запросами | 10 секунд |
| Запросов в час на пользователя | 20 |
| Ожидающих в очереди обработки | 8 |
| Запросов, ожидающих выбора языка | 32 |
| Время выбора языка | 10 минут |

Обработка последовательная. Кнопки проверяют Telegram ID и случайный идентификатор запроса. Чужие, устаревшие и повторные нажатия не создают новую работу. Лимиты частоты хранятся в памяти и сбрасываются при перезапуске. Для файлов сверх 20 МБ нужен иной способ доставки или собственный Telegram Bot API server; в этой версии он не реализован. PDF, изображения и архивы не распознаются.

## Конфигурация

`config.example.json` содержит все параметры. Реальный `config.json` исключён из Git.

- `bot_token`: токен вашего бота.
- `idle_seconds`, `port`: время простоя и локальный порт Whisper.
- `max_file_mb`, `max_duration_seconds`: ограничения медиа.
- `queue_size`, `cooldown_seconds`, `requests_per_hour`: очередь и антиспам.
- `allowed_user_ids`: пустой список — публичный доступ; `[123456789]` — только перечисленные Telegram ID.
- `privacy_url`: необязательная ссылка на вашу политику обработки данных; показывается в разделе «Конфиденциальность».

Часть подсказок и срок выбора языка в исходной версии заданы прямо в коде. Если меняете лимиты в конфигурации, проверьте соответствующие тексты. Это сохранённая рабочая версия, а не универсальная конфигурируемая платформа.

## Данные и безопасность

Аудио передаётся Telegram и компьютеру владельца; отдельный облачный сервис распознавания не используется. Временные файлы удаляются после обработки, ошибки и штатной отмены. После аварийного выключения остатки могут сохраниться в `temp/`. Бот не архивирует расшифровки, но сообщения остаются в Telegram. Технические журналы содержат диагностику, длительность, язык и время обработки; данные Whisper могут попадать в локальный журнал.

Не публикуйте `config.json`, `.env`, `logs/`, `temp/`, `preferences.sqlite3` или ключи публикации страниц. Если токен случайно попал в GitHub, сначала отзовите его через BotFather; удаления файла из нового коммита недостаточно.

## Проверки

Для unit-тестов достаточно зависимостей и конфига с фиктивным токеном: модель и GPU не нужны.

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
Copy-Item config.example.json config.json  # только если своего config.json ещё нет
.venv\Scripts\python.exe -m unittest -v test_bot
```

`test_bot.py` проверяет выбор четырёх языков, отсутствие обработки до выбора, чужие/повторные кнопки, отмену, очередь, ошибки сети, тишину и лимиты. `selftest.py` проверяет реальное распознавание, выгрузку и повторную загрузку модели; `check_cancel.py` — отмену инференса. Перед GPU-тестами остановите бота и установите runtime/модель через `setup.bat`.

## Если не работает

- **Нет Python:** переустановите Python x64 с Launcher или PATH.
- **Нет `.venv`, модели, runtime:** выполните `setup.bat`; проверьте ошибки сети и контрольной суммы.
- **Модель не стартует:** откройте `logs/whisper.log`, обновите AMD-драйвер с Vulkan, проверьте свободную VRAM и что порт 18088 не занят.
- **Telegram Conflict:** другой процесс использует тот же токен; остановите его. Уберите webhook, если токен ранее использовался с webhook.
- **Неверный токен:** проверьте `config.json` и BotFather.
- **Долго после простоя:** первый запрос загружает модель и подготавливает GPU.
- **Нет звука:** нужен аудиотрек; FFmpeg отвергает повреждённые файлы и видео без звуковой дорожки.
